# LibreDeck ESP32-S3 Waveshare 1.75C Web Flasher

Web-based firmware installer for running [LibreDeck](https://github.com/elModo7/LibreDeck) on the Waveshare ESP32-S3 1.75C.

No additional software required. Just connect your device via USB and flash it directly from your browser.

**[Open Web Flasher](https://elmodo7.github.io/LibreDeck-ESP32-Waveshare-1.75C-flasher/)** | **[LibreDeck GitHub Repository](https://github.com/elModo7/LibreDeck)**

## How to install

1. Connect your Waveshare ESP32-S3 1.75C to your computer via USB.
2. Open the web flasher using Chrome or Edge.
3. Click **Connect & Install** and select your device.
4. Wait for the installation to finish. It may take a little longer at 99%.
5. If the device doesn't restart automatically, press the RESET button.
